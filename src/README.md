# Modules

| module | content |
| -- | -- |
| algebra | vectors, matrices, quaternions |
| asset | loading and managing assets like shaders, textures, models etc. |
| client | client-side application loop and network connection handling |
| coordinate | layout of and conversion between coordinate systems |
| glfw-wgpu | glue code between GLFW and wgpu-native (might go into a separate library) |
| graphics | rendering of scene objects |
| gui | window handling, user interface elements, input events |
| module | loading and managing game modules and their resources |
| protocol | data structures exchanged between client and server |
| scene | client-side game state presented to a specific player |
| server | server-side application loop and network handling |
| simulation | game logic updates |
| world | server-side game state |
